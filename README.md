# Wallet API

REST API для работы с кошельками пользователей: пополнение, снятие и
получение баланса. Реализовано как тестовое задание.

## Стек

- Python 3.14, FastAPI (async)
- PostgreSQL 17, SQLAlchemy 2 (asyncpg), Alembic
- Poetry, Docker, docker-compose
- pytest, pytest-asyncio, httpx
- ruff (линтер и форматтер, PEP8, длина строки 79)

## Запуск

Нужны только Docker и Docker Compose. Одной командой поднимаются
приложение и база данных, миграции применяются автоматически при старте:

```bash
docker compose up --build
```

После запуска:

- API: <http://localhost:8000>
- Swagger UI: <http://localhost:8000/docs>

Остановить и удалить контейнеры:

```bash
docker compose down
```

Чтобы удалить и данные базы, добавьте флаг `-v`.

## API

Базовый префикс: `/api/v1`.

| Метод | URL                                | Описание                  |
|-------|------------------------------------|---------------------------|
| POST  | `/api/v1/wallets`                  | Создать кошелёк           |
| GET   | `/api/v1/wallets/{wallet_uuid}`    | Получить баланс кошелька  |
| POST  | `/api/v1/wallets/{wallet_uuid}/operation` | Пополнение или снятие |

Эндпоинт создания кошелька не входит в задание, но нужен, чтобы было с
чем работать: баланс нового кошелька равен `0.00`.

### Создать кошелёк

```bash
curl -X POST http://localhost:8000/api/v1/wallets
```

Ответ `201 Created`:

```json
{
  "wallet_id": "3f2b8c1e-9a4d-4e57-b6a1-0c9d2e7f5a10",
  "balance": "0.00"
}
```

### Изменить баланс

```bash
curl -X POST http://localhost:8000/api/v1/wallets/<WALLET_UUID>/operation \
  -H "Content-Type: application/json" \
  -d '{"operation_type": "DEPOSIT", "amount": 1000}'
```

Тело запроса:

| Поле             | Тип      | Описание                                    |
|------------------|----------|---------------------------------------------|
| `operation_type` | string   | `DEPOSIT` (пополнение) или `WITHDRAW` (снятие) |
| `amount`         | decimal  | Сумма, больше 0, не более 2 знаков после запятой |

Ответ `200 OK` содержит кошелёк с новым балансом:

```json
{
  "wallet_id": "3f2b8c1e-9a4d-4e57-b6a1-0c9d2e7f5a10",
  "balance": "1000.00"
}
```

### Получить баланс

```bash
curl http://localhost:8000/api/v1/wallets/<WALLET_UUID>
```

Ответ `200 OK`:

```json
{
  "wallet_id": "3f2b8c1e-9a4d-4e57-b6a1-0c9d2e7f5a10",
  "balance": "1000.00"
}
```

Баланс возвращается строкой, чтобы не терять точность десятичных чисел.

### Коды ответов

| Код | Когда возвращается                                              |
|-----|-----------------------------------------------------------------|
| 200 | Операция выполнена, баланс получен                              |
| 201 | Кошелёк создан                                                  |
| 404 | Кошелёк не найден                                               |
| 409 | Недостаточно средств для снятия                                 |
| 422 | Некорректные данные: неверный UUID, тип операции или сумма      |

## Конкурентность

Изменение баланса выполняется одним атомарным SQL-запросом:

```sql
UPDATE wallets SET balance = balance + :amount WHERE id = :id;
-- для снятия: добавляется условие balance >= :amount
```

Блокировку строки обеспечивает PostgreSQL, поэтому параллельные запросы
к одному кошельку не теряют обновления и не уводят баланс в минус.
Дополнительно в таблице есть ограничение `CHECK (balance >= 0)`.

## Тесты

Тесты используют отдельную базу, контейнер `db-test` (порт `5434`).
Для запуска нужен Python 3.14 и Poetry.

```bash
docker compose up -d db-test
poetry install
poetry run pytest
```

Адрес тестовой базы по умолчанию:
`postgresql+asyncpg://wallet_user:{password}@localhost:5434/wallet_test_db`.
Его можно переопределить переменной окружения `TEST_DATABASE_URL`.

В тестах проверяются:

- создание кошелька и получение баланса;
- пополнение и снятие, ответы 404, 409 и 422;
- параллельные пополнения и снятия одного кошелька.

## Конфигурация

Настройки читаются из переменных окружения с префиксом `APP_CONFIG__`
(вложенные поля разделяются `__`), а также из файла `.env`.
Пример значений лежит в `.env.template`.

| Переменная              | Описание                              |
|-------------------------|---------------------------------------|
| `APP_CONFIG__DB__URL`   | Адрес подключения к PostgreSQL        |
| `APP_CONFIG__DB__ECHO`  | Логировать SQL-запросы (по умолчанию `false`) |

В `docker-compose.yaml` переменная `APP_CONFIG__DB__URL` уже задана для
контейнера с приложением.

## Миграции

Миграции Alembic лежат в `src/alembic/versions`. В Docker они
применяются автоматически командой `alembic upgrade head` перед запуском
приложения. Вручную, из каталога `src`:

```bash
alembic -c alembic.ini upgrade head
```
